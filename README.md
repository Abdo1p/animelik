# animelik (أنمي ليك) - منصة مشاهدة وتحميل الأنمي المترجم

نسخة مستنسخة بالكامل ومطورة من موقع **eva.animerco.org** بهوية **animelik**، تضم كامل التصميم، الأقسام، المشغلات متعددة السيرفرات، وجدول المواعيد الأسبوعي.

## 🚀 المميزات الرئيسية
- **مشغل فيديو متعدد السيرفرات:**
  - سيرفر Yonaplay VIP (Embed)
  - سيرفر Google Drive FHD (HTML5 Direct)
  - سيرفر Vidmoly Multi
  - سيرفر StreamWish HD
  - سيرفر Mp4Upload Fast
- **ميزة إطفاء الأنوار (Cinema Mode):** لتجربة مشاهدة مريحة في الظلام.
- **سلايدر أنميات مميزة:** مع العنوان الرأسي المميز للموقع الأصلي `أنــــمــــيــــات مــــمــــيــــزة`.
- **أقسام الصفحة الرئيسية:**
  - الأنميات المثبتة مع شارات المواسم
  - الحلقات المثبتة
  - آخر الحلقات المضافة مع توقيت النشر المباشر
  - آخر الأنميات المضافة
  - آخر أفلام الأنمي المضافة
- **جدول مواعيد الحلقات الأسبوعي:** من السبت إلى الجمعة مع تحديد اليوم الحالي.
- **تصفية وبحث متقدم:** فلترة حسب النوع، الحالة (مستمر / مكتمل)، التصنيف، والموسم.
- **بحث فوري (Live Search Modal):** بحث أثناء الكتابة مع دعم الاختصار `Ctrl+K`.
- **المفضلة وسجل المشاهدة:** حفظ الأنميات ومتابعة الحلقات المشاهدة محلياً.
- **جدول روابط التحميل المباشر:** بجودات 1080p FHD، 720p HD، 480p SD.
- **نظام التعليقات مع حماية الحرق (Spoiler Protection).**

## 🛠️ متطلبات التشغيل
- Node.js 18+ أو أعلى
- npm أو pnpm أو yarn

## 📦 التثبيت والتشغيل
```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build
```
